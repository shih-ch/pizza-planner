# 團體比薩試算

團體訂比薩時，先照想吃的品項單點選餐，再自動比較必勝客的套餐、APP 優惠、外帶買大送大，以及拿坡里炸雞的裝桶組合，找出最省的買法。

**線上使用：<https://shih-ch.github.io/pizza-planner/>**

原始碼：<https://github.com/shih-ch/pizza-planner>

## 功能

- 單點選餐：口味、尺寸、餅皮、數量，並附官網商品連結
- 依人數、每人片數、炸雞塊數、飲料量快速填入清單
- 推薦方案：比對 10 人以上套餐、Hot 拼盤餐、一公尺派對盒、三個大比薩，以及優惠券（APP 外帶 5 折送烤雞、外送 7 折、大比薩分享餐、買大送大、外送買大送小、平日限時價），依含拿坡里的總價與每人餐費排序
- 優惠券每單限用張數可設定；官網寫「各項優惠不得併用」，方案會標示需分幾張單
- 必勝客優惠券贈送的烤雞可自動抵掉拿坡里炸雞的塊數
- 每種套餐與優惠券都能個別開關，一鍵切換「不用優惠券」比較差多少，另有「重新計算」按鈕
- 選定方案後產生訂購清單（必勝客、拿坡里分開列），可一鍵複製貼到 LINE，可選擇附上官網連結
- 依用餐日期檢查活動：平日外帶限時價、7 日預約上限、已結束的活動
- 優惠的口味加價：APP 券、三個大比薩、分享餐以「基本價＋口味等級加價」計算，加價可照 APP 顯示修改，留空代表該等級不能選
- 估計值（片數、餅皮加價、套餐換口味加價）可在頁面上修改

## 使用

直接用瀏覽器開 `index.html`，或用 GitHub Pages 發布。單一檔案，不需建置、沒有後端。

## 資料

- 必勝客價格：2026/10/13 取自官網
- 餅皮加價：2025/11 媒體報導
- 拿坡里價格：2026/5 菜單整理

價格會變動，更新時修改 `index.html` 內 `PIZZAS`、`ITEMS`、`SETS`、`NP`、`EST` 等常數。

## 聲明

非官方工具，與必勝客、拿坡里無關。價格與活動以各品牌官網及門市公告為準。
